# Estado de permanencia de clientes

Proyecto introductorio para cargar datos uy clasificar clientes según su estado

## Objetivo

Mostrar clientes que siguen utilizando el servicio y cuales no.

## Ejecución

Ejecutar el programa  desde la raiz del proyecto: python3 src/estado_clientes.py
